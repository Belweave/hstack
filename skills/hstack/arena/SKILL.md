# Arena

## When to Use

A design or an approach has no obvious winner, and the user wants the attempts built. A throwaway experiment they will delete is bundled `spike`.

## What to do

Give several attempts the same brief. Put each attempt in its own worktree with `/worktree`.

Read the attempts. Keep the best pieces. Delete the rest. Do not leave the losing trees as extra branches unless the user asked to see them.

This is not `swarm`. Swarm partitions the work. Arena duplicates the same brief.

Load `shape` if the data and the owning module are not named yet. Load `principles` if a rule should decide the winner.
