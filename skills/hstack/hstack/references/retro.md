# Retro

Use this for a weekly retro or a quality snapshot. Read only.

1. Read recent commits and open pull requests. Load `github` with `skill_view("github")` for the `gh` flags.
2. Say what shipped, what stuck, and what failed its checks.
3. Recommend one change to the way of working. Do not file it unless asked.
4. Do not start a dashboard or a metrics service.
