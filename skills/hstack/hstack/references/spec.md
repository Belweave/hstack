# Spec

Use this when the user wants a written plan, a phased change, or no route fits.

1. If the job is still unnamed, load `reframe` with `skill_view("reframe")` and stop.
2. Load `shape` with `skill_view("shape")`. Then use `/plan` when they want a file.
3. Phases become sections of that plan, or Kanban cards. Do not invent a second tracker.
4. Do not ask a question the repo can answer. A preference uses `clarify`.
5. When no route fits, write five lines: the job, the check, the stop line, the files you expect to touch, and what you will not do. Then do that.
