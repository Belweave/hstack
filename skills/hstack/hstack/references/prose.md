# Prose

Use this when the wording is the job, or the user wants the last reply in plain words.

1. Load `humanizer` with `skill_view("humanizer")` and follow it. Do not keep a private word list.
2. A plain restatement is shorter, with concrete nouns and no preamble.
3. Comments that only narrate the next line are a review finding. Load `requesting-code-review` with `skill_view("requesting-code-review")` when the diff is the target.
