# Memory

Use this to save or restore working context.

1. Restore with `session_search` and the `memory` tool. Do not invent notes that are not there.
2. Save only what the next session cannot get from the repo. Stay inside the tool's size caps.
3. A repeated lesson can become a skill with `/learn` when the user asks.
4. Do not install a second memory database. Do not rewrite project instruction files to point at one.
5. A session stamp may exist at `session-log.tsv` under the HStack directory in the Hermes home. Read the last line if the file is there. It is absent when the session hook is not installed.
