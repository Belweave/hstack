# Pickup

Use this to resume, pause, or catch up.

1. Catch-up: what changed since the user's last message, and what is waiting on them. `/status` is the local recap.
2. Pause: write the branch, the last check that passed, and the next command. Do not leave unrelated edits.
3. Resume someone else's branch: load `takeover` with `skill_view("takeover")`. Keep their git author.
4. Resume this session's own work from the transcript.
