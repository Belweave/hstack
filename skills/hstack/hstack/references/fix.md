# Fix

Use this when something is broken.

Read the code and the git history before explaining a cause. Do not guess a cause from the symptom.

Load `systematic-debugging` with `skill_view("systematic-debugging")` and follow it. Do not restate it here.

A bug with a cheap local test: load `test-driven-development` with `skill_view("test-driven-development")` before the edit.

Then load `prove` with `skill_view("prove")`. Show the failure, then the passing check, on the real behavior.
