# Design

Use this for a visual critique, a layout, or friction while using the thing.

1. Name the job the screen or the command is for. If that is still open, load `reframe` with `skill_view("reframe")` and stop.
2. Capture the real surface. For a page, load `dogfood` with `skill_view("dogfood")` and follow it. Save a screenshot. For a command, run it.
3. Name what is wrong: hierarchy, spacing, contrast, or a step that wasted time. One list.
4. If the user wants several layouts, load `arena` with `skill_view("arena")` and keep the best parts.
5. Load `design-md` with `skill_view("design-md")` only when they asked for a design-system file.
6. Motion is a before screenshot and an after screenshot. Render a video only when an encoder is already installed.
7. A device or simulator runs only when the user already set it up.
