# Parallel

Use this to split work or to race approaches.

1. Different files or different questions: load `swarm` with `skill_view("swarm")`.
2. The same brief, several attempts: load `arena` with `skill_view("arena")`.
3. Do not build a merge train. The user merges, or `ship` does, and only when they said to send.
4. Children do not spawn their own panels and do not watch pull requests.
