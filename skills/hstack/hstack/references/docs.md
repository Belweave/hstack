# Docs

Use this for a missing doc, a release note, a README, or a PDF.

1. Pick one shape: tutorial, how-to, reference, or explanation. Write that one.
2. Lead with the problem the reader has. Do not open with a file list.
3. For a pull request, load `ship` with `skill_view("ship")`.
4. For a markdown PDF, load `pdf` with `skill_view("pdf")`. Do not invent a layout engine.
5. If the wording is the complaint, stop and load `references/prose.md` the same way you loaded this file.
